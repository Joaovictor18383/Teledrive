# TeleDrive

Projeto multiplataforma em desenvolvimento, com foco em armazenamento, backup e acesso a arquivos.

## Plataformas planejadas

- **Windows:** instalador ou executável `.exe`.
- **Linux:** pacotes `.deb` e `.AppImage`.
- **Android:** pacote instalável compatível com o projeto.

## Atualizações

A meta é automatizar as compilações e publicações pelo GitHub Actions e disponibilizar atualizações para os usuários quando uma nova versão for lançada. O funcionamento e o método de atualização de cada plataforma serão definidos após a análise do código-fonte.

## Estado do projeto

Este repositório foi criado para organizar o projeto. O código-fonte original ainda precisa ser enviado e revisado antes de confirmar os recursos, dependências e comandos de compilação.

## Documentação

As instruções de instalação, configuração, uso e desenvolvimento serão completadas depois da análise dos arquivos originais.
